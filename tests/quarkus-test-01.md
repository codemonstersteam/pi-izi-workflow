## Живые proof'ы механики

1. **resume**: прогон перезапускался 3 раза (foreground-цикл → фикс → confirm-цикл → фикс) —
   каждый раз продолжал с маркера, не с нуля.
2. **Круги починки plan**: судья поймал цитату не-подстроку → FEEDBACK → круг 2 → зелёный.
3. **Вопросы из чата**: 5 вопросов с рекомендациями → followUp в чат → оператор ответил →
   solo_answer (TypeBox-схема) → answers.md → вписаны в план («→ РЕШЕНО»).
4. **Подтверждение словами**: «да» → execute; не потребовалось checkpoint-модалки.
5. **Судьи execute**: (a) 3/3 Ф↔коммиты · (b) тесты только расширены (+55, 0 удалено) ·
   (c) гарантии §5 — 0 строк удалено из гарантированных файлов.
6. **Тишина**: на экране только карточки полосы (say→log) и вопросы (followUp) — без шума.
