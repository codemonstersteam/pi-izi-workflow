## 2. Вердикт по гипотезе оператора

**Качество — да, но не за счёт узости инструкции.** Д3 куплен на узкой инструкции. Качество прибывает
из трёх других вещей: (а) срез с ДРУГИМ ВХОДОМ (поток данных, которого сегодня не видит никто после
шага 9), (б) машинное сведение срезов с поиском противоречий, (в) счётные правила там, где суждение не
нужно (Д2, Д4, половина Д3 — бесплатны). Поэтому декомпозиция здесь — один новый срез плюс три правила
скрипта, а не пять ролей.

**Скорость — нет.** Шаг 11 сегодня — один вызов на круг; N срезов — N вызовов. `parallel()` с
литеральными слотами (как рой: `workflows/izi.js:539,571-580`, BUG_FIX_CONTEXT validation.ts:755)
даёт стену круга ≈ max(срезов) ≈ сегодняшнему одному вызову — ПАРИТЕТ, не выигрыш. Последовательно —
минус ~2 мин на 22-минутном прогоне. В этой части гипотеза оператора неверна, и это результат.
Косвенная экономия одна: пойманный на круге 1 дефект не превращается в ложный Pass, чья цена —
ручная находка и новый прогон (~400 K токенов), против +30 K за срез.

## 5. Сведение — скрипт, не роль

Третьей роли-сводчика НЕТ: сведение — счёт, а роль-сводчик была бы сертификатором (CLAUDE.md,
constraint 1). Правится `review()` (`ext/index.mjs`) + чистая `mergeReview` в `review.mjs`:

1. Каждый срез пишет свой staging (`review-plan.xml`, `review-flow.xml`), форма каждого судится своими
   правилами (A — R1..R5 + R6/R7 ниже; B — свои R1/R2/R5-аналог по owed-B). Красная форма —
   пере-делегация ТОЛЬКО красного среза, счётчик `attempt` на срез, общий `LOOPS`.
2. Обе формы зелены → `mergeReview({ a, b, auto })`: находки объединяются, `autoFindings` как сегодня.
3. **Противоречие** — один id, ЗАКРЫТЫЙ (`covers`) одним срезом и ОБВИНЁННЫЙ (evidence/node блокера)
   другим. Пример из наряда оператора — «покрытие закрыло пункт узлом, проверяемость объявила узел
   неисполнимым» — НЕ противоречие: это два совместимых факта об одном узле (отвечает за пункт И
   непроверяем), оба остаются, итог Reject по блокеру. Противоречие — два несовместимых утверждения об
   одном id (доставлен/не доставлен). Разрешение детерминированное: блокер побеждает, `covers`
   аннулируется, вердикт Reject, факт помечается в артефакте — срез, судивший без входа второго среза,
   не может перевесить срез, который провал ВИДЕЛ.
4. Сводный артефакт — `.agent/review.xml`, `grammar="3"`, аддитивно: `<covers slice="plan|flow" …/>`,
   `<blocker slice=… />`, `<witness node cmd/>` (R6), `<conflict item=…/>`. Потребители: `band()`
   (читает findings из результата `review()` — форма не меняется, плюс owner 9), `docs/review.md` §7;
   шага 12 нет.
