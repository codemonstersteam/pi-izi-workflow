артефакт `.agent/brd.md` собирает скрипт, а модель отвечает ОДНОЙ строкой — какая существующая вещь
служит образцом новой. Форма артефакта после этого не может быть сломана в принципе.

### TICKET A05 — голова подшага: модель пишет строку, артефакт собирает скрипт

**io:** fs + model → компонентных сценариев 3.

**Суть тикета одной фразой.** `fold` получает от модели ОДНУ строку, судит её, собирает артефакт
скриптом, продвигает и зовёт карту обхода.

```
next  → наряд аналога → роль analogue → .agent/staging/analogue.txt   (одна строка)
fold  → T4(строка, hits) → assemble.brdText(numbered, строка, subjectsOf)
      → .agent/staging/brd.md → promote → .agent/brd.md → spread → .agent/anchors.json
```

**Что это чинит.** Сегодня артефакт пишет модель, и потому он бывает не похож на артефакт вовсе —
для этого в судье живёт класс `invalid` и вся тотальность вокруг него. Когда файл собирает скрипт,
непохожего артефакта не существует; остаётся один вопрос — верно ли слово аналога.

**Переименование.** `steps/brd/gate/` → `steps/brd/anchors/`; id шага `brd/gate` → `brd/anchors`;
имя роли `gate` → `analogue`; имя паузы `brd-gate` → `brd-anchors`. Швы: `ext/state.mjs::STEPS`,
`ext/vocabulary.test.mjs`, обёртка `brd(state)` в `workflows/izi.js`.
