Создать standards/ts-skill.md — стандарт TS-кода для этого репозитория

Содержание (основано на трёх статьях + pinout-asyncapi + текущем коде ext/run.ts):

1. Модуль = функция с одной задачей (один вход, один выход, дерево иерархии)
2. Value objects valid-by-construction (private constructor + static of → Result)
3. Result<T> везде (никаких throw/null для ожидаемых отказов, ROP-пайп)
4. Воркфлоу — ROP из трёх вызывов (head не юнит-тестируется)
5. Формулы: юниты = 1 + Σ ветвей антецедента; компонентные = 1 + Σ ветвей адаптера
6. Самовалidация: швы для каждого правила
7. Принципы из статей, применённые к коду этого репо
