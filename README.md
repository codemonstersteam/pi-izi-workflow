# solo

Воркфлоу планирования и разработки для pi-extensible-workflows: модель с полным доступом
к коду пишет PLAN.md по шестираздельной артефакт-спеке, судьи и критик конвейера проверяют,
оператор утверждает, разработка идёт по строкам плана (строка Ф = коммит).

- Дизайн: `PLAN.md`. Стандарты кода: `standards/`.
- Установка: `pi install ./ext` (один раз на машину).
- Запуск: в каталоге проекта с TASK.md → `pi` → `/solo` (foreground, чат-модель — кнопка).
- Проверка: `node --test`.
