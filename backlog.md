# Бэклог — шаг 4 `scope`

Концепт утверждён оператором: `docs/scope.md`. Итерация = задача + её тест + отметка здесь.
Красный `node --test` — результат, о котором сообщают, а не повод править тест.

Шаг 4 — первый **веер** полосы: роль `scout`, батчи по `maxParallel`, оператора нет вовсе.
Правила гардрейла объявлены один раз — `docs/scope.md` §3 (C1 · S1..S5 · P1..P3); ни бэклог, ни роль,
ни наряд их не пересказывают.

С этого среза действуют два решения оператора, и они не отдельная задача, а форма каждой из них:
**Zero-Context Survival** (`MODULE_CONTRACT` · `FUNCTION_CONTRACT` · `BUG_FIX_CONTEXT` ·
`EXTERNAL_DEPENDENCY`) и **язык** — код, комментарии, роль, наряды и тесты по-английски; русский
только там, где читает оператор (`docs/*.md`, `backlog.md`, `subject`, `log`).
